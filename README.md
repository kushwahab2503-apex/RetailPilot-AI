# RetailPilot AI

> AI-Powered Retail Business Intelligence Platform

RetailPilot AI is an enterprise retail analytics and decision support platform that turns raw transaction data into deterministic business intelligence. It provides automated data validation, revenue tracking, customer cohort analysis, product performance metrics, and audit-ready executive reports. All insights and health diagnostics are computed using transparent, explainable rule-based logic.

## Key Features

- **Data Ingestion & Cleaning:** Multi-point CSV schema validation and non-destructive data cleaning.
- **Revenue & Product Analytics:** Sales growth tracking, SKU velocity, and Pareto (80/20) concentration analysis.
- **Customer Intelligence:** Repeat-purchase behavior, cohort retention trends, and concentration risk metrics.
- **Forecasting & Diagnostics:** Baseline demand trend modeling and multi-domain business health assessments.
- **Executive Reporting:** One-click exportable PDF and CSV summary reports.

## Tech Stack

- **Frontend:** Streamlit
- **Data Processing:** Python, Pandas, NumPy
- **Reporting & Visualization:** Matplotlib, fpdf2
- **Testing:** Pytest

## Quick Start

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
streamlit run .\app\main.py
```
